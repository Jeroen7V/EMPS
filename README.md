# ESCPOS Markdown Printing Service (EMPS)

EMPS is a small FastAPI service that receives markdown over HTTP, translates
it to an ESC/POS byte stream, and prints it on a USB receipt/thermal printer.
It also ships a **Home Assistant custom integration** that exposes the
printer to HA: health sensors, a test-page button, and
`emps.print_markdown` / `emps.print_test_page` service actions.

## Quick start: the service

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'

# Dry run (writes raw ESC/POS bytes to a file, no printer needed):
PRINTER_BACKEND=file PRINTER_OUTPUT_FILE=/tmp/escpos.bin \
  .venv/bin/uvicorn emps.api:app --host 0.0.0.0 --port 8000

# On the machine with a USB printer attached:
PRINTER_BACKEND=usb USB_VENDOR_ID=0x04b8 USB_PRODUCT_ID=0xe035 \
  .venv/bin/uvicorn emps.api:app --host 0.0.0.0 --port 8000
```

Try it:

```bash
curl -X POST http://localhost:8000/print/test          # built-in feature test page

curl -X POST http://localhost:8000/print \
  -H 'Content-Type: application/json' \
  -d '{"markdown": "# Order 123\n\n- **Pizza** margherita\n- Cola\n\nTotal: **12.50**"}'
```

Detailed deployment (Docker, udev/USB permissions, all environment variables
including the optional `EMPS_AUTH_TOKEN`) is in
[docs/deployment.md](docs/deployment.md); the full endpoint reference and
markdown→ESC/POS mapping table are in [docs/api.md](docs/api.md).

## Quick start: Home Assistant

- **HA 2026.11+**: Settings > Marketplace, search **EMPS**, install, then
  add the *EMPS* integration and point it at the service's host/port.
- **Older installs**: add this repository to HACS as a custom repository
  (category *Integration*).
- No custom component? The YAML-only `rest_command` recipe works too.

See [docs/home-assistant.md](docs/home-assistant.md) for setup, entity
reference, and ready-made scripts for printing messages and To-do lists.
